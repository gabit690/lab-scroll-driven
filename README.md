# Lab scroll-driven animation

A Zelda-themed experiment exploring CSS scroll-driven animations.

## Stack

- HTML5
- CSS3

## Local demo

### Prerequisites

- Python 3

No build step or additional dependencies are required.

### Setup

1- Clone the project repository.

```bash
git clone https://github.com/gabit690/lab-scroll-driven.git
```

2- Navigate to the project directory.

```bash
cd lab-scroll-driven
```

3- Start the local HTTP server.

```bash
python3 server.py
```

4- Open http://localhost:8000 in a browser.
